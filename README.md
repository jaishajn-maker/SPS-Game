# Stone Paper Scissors Game

A simple console-based Stone Paper Scissors game where the user plays against the computer.

## How to Run
1. Make sure Python is installed on your computer.
2. Clone this repository:
   git clone spsgame.py
3. Navigate into the folder:
   cd SPS-Game
4. Run the game:
   python spsgame.py
5. Follow the on-screen prompts to play.

## Features
- Menu with Stone, Paper, Scissors options
- Random computer choice
- Displays both choices and the winner
